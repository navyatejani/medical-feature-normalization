# Medical Diagnostic Image Feature Normalization Engine


A machine learning project that standardizes breast cancer diagnostic features and optimizes classification performance to maximize Recall (Sensitivity).


Dataset
Breast Cancer Wisconsin (Diagnostic) Dataset.
Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Streamlit
Key Features
- Exploratory Data Analysis
- Feature Scaling and Normalization
- Machine Learning Model Training
- Hyperparameter Tuning
- Recall-focused Model Evaluation
- Streamlit Web Application
Run the Project
Install the dependencies:

pip install -r requirements.txt

Run the application:

streamlit run app.py
